# Sales Data Analysis — Data Analyst Work Sample

## Objective
Analyze a small retail sales dataset to identify revenue trends, category performance, geographic performance, and basic data-quality issues.

## Tools
- Python
- Pandas
- Matplotlib
- CSV

## Analysis performed
1. Checked missing values and duplicate order IDs.
2. Calculated total revenue, total orders, and average order value.
3. Compared revenue by product category.
4. Compared revenue across cities.
5. Analyzed monthly revenue trends.
6. Created a simple revenue trend visualization.

## How to run
```bash
pip install pandas matplotlib
python analysis.py
```

## Dataset
`sales_data.csv` is a synthetic dataset created for demonstration purposes and does not contain real customer information.

## Key analyst approach
The project focuses not only on calculating metrics, but also on validating data quality before interpreting changes in business performance.
